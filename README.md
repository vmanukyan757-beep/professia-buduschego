# Профессия будущего

Тест на профессию, устойчивую к замене ИИ. Вопросы идут по дереву «да / нет» (обычно 10–15 ответов до результата). Ответ «да» на инженерию ведёт глубже в инженерию, «нет» переводит к медицине, затем к стройке, людям и творчеству. Есть обязательный вход по имени/нику (для учёта уникальных пользователей), счётчики заходов и прохождений, оценка сайта звёздами и кнопка доната.

Зависимостей нет, нужен только [Node.js](https://nodejs.org) 18 или новее.

## Запуск в VS Code

1. Откройте папку проекта: `File → Open Folder`.
2. В терминале VS Code (`Ctrl+\``) выполните:
   ```
   npm test
   npm start
   ```
3. Откройте http://localhost:3000. Либо нажмите F5: конфигурация «Запустить сайт» уже есть в `.vscode/launch.json`.

Счётчики и оценки сохраняются в `data/stats.json`.

## Как устроено

| Файл | Что внутри |
| --- | --- |
| `public/tree.js` | Все вопросы, ветвления и профессии. Здесь правится содержание. |
| `public/app.js` | Экраны теста, отправка прохождений и оценок |
| `public/index.html` | Страница с мета-тегами для поиска и каталогом профессий |
| `server.js` | Раздача сайта, API счётчиков, `robots.txt` и `sitemap.xml` |
| `test/tree.test.js` | Проверка, что в дереве нет битых ссылок и недостижимых профессий |

### Как менять дерево

В `tree.js` каждый вопрос выглядит так: `e1: { d: 'eng', q: 'Вопрос?', y: 'e2', n: 'e5' }`. Поле `y` ведёт при «Да», `n` при «Нет». Значение `L:robotics` означает «закончить на профессии robotics». После правок запустите `npm test`: он найдёт ошибки в ссылках.

## Как выложить в интернет

Чтобы сайт открывался у всех, его нужно разместить на сервере с Node.js. Подойдут Render, Railway, Fly.io или обычный VPS.

Важно: счётчики пишутся в файл, поэтому нужен **постоянный диск**. На бесплатных тарифах многих хостингов файловая система стирается при каждом перезапуске, и счётчики обнулятся. Либо подключите диск и укажите его путь в `DATA_DIR`, либо возьмите VPS.

Переменные окружения:

| Переменная | Зачем |
| --- | --- |
| `SITE_URL` | Адрес сайта без слэша, например `https://profession2035.ru`. Нужен для canonical, Open Graph и sitemap. |
| `PORT` | Порт. Большинство хостингов задают его сами. |
| `DATA_DIR` | Папка для `stats.json` |
| `TRUST_PROXY` | `1`, если сайт стоит за nginx или Cloudflare, чтобы защита от накрутки видела настоящие IP |
| `ADMIN_TOKEN` | Секрет для `/api/admin?token=...`: покажет, какие профессии выпадают чаще |

HTTPS обычно включается на самом хостинге. Свой домен покупается у любого регистратора и привязывается в настройках хостинга.

## Чтобы сайт находили в Google и Яндексе

Страница уже содержит заголовок, описание, Open Graph, структурированные данные и текстовый каталог всех профессий. Это основа, но сайт не появится в поиске мгновенно.

1. Выложите сайт на домен с HTTPS и задайте `SITE_URL`.
2. Зарегистрируйте сайт в [Google Search Console](https://search.google.com/search-console) и [Яндекс Вебмастере](https://webmaster.yandex.ru).
3. Отправьте `https://ваш-сайт/sitemap.xml` в обоих сервисах.
4. Подождите: первая индексация занимает от нескольких дней до нескольких недель.

Обратите внимание: место в выдаче по запросам вроде «какая профессия мне подойдёт» зависит от конкуренции и ссылок на сайт. Название «Профессия будущего» появится по запросу к нему довольно быстро, а высокие позиции по общим запросам требуют времени, полезного контента и ссылок с других сайтов.

## Как работают счётчики и оценки

* **Заходы**: один раз за сессию браузера.
* **Пользователи**: уникальные имена/ники (хешируются, сами имена не хранятся).
* **Прошли тест**: когда человек дошёл до результата.
* **Оценка**: один голос на посетителя. Повторная оценка заменяет прежнюю. В файле хранится только необратимый хеш от IP и браузера, самого IP там нет.
* **Защита**: не более 30 запросов в минуту с одного IP, проверка входных данных, ограничение размера запроса.

Это защита от случайной и грубой накрутки, но не от целенаправленной атаки с разных адресов.

## Что стоит помнить

Оценки устойчивости к ИИ (поле `r` в `tree.js`) заданы автором как условные баллы для сравнения профессий. Это не научный прогноз. Если сайт станет публичным, стоит оставить на странице оговорку о том, что результат остаётся ориентиром.

## Донат
